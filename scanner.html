Thiết lập Google Sheet / Drive

Google Sheet không lưu được file trực tiếp, nên trang này gửi PDF tới một Google Apps Script do bạn triển khai: script sẽ lưu file PDF vào Google Drive và ghi một dòng (tên file, thời gian, link Drive) vào Google Sheet. Đoạn code Apps Script và hướng dẫn triển khai nằm trong phần trả lời bên dưới.
